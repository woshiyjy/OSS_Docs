# 番茄生长和发育过程

## 花芽分化：营养生长到生殖生长的转折

樱桃番茄幼苗出土后，从第一片真叶显露到长出 2～3 片真叶这段时间，植株以根系发育和叶片生长为主，属于纯营养生长阶段，通常持续 25～30 天。当幼苗长至 2～3 片真叶平展时，第一花序的花芽便开始分化，这是植株由营养生长转向生殖生长的内在生理转折点。从这一刻起，营养生长与生殖生长便同时进行、并进发展，这一并进状态会一直持续到生长结束。

番茄花芽分化具有「早而快、连续性」的突出特点：

- 大约每 **2～3 天**分化一个花芽
- 每 **10 天**左右分化一个花序
- 第一花序分化尚未结束时，第二花序已开始分化
- 当第一花序呈现大蕾时，第三花序往往已分化完毕

这种层层递进的连续分化，使番茄的营养生长与生殖生长长期交织、互相影响。

樱桃番茄主茎生长至第 **8～9 节**（或 7～10 片真叶）处着生第一花序，此后每隔 **2～3 节**着生一个花序；中晚熟品种通常每隔 3 片叶着生一个花序。

花芽分化虽是内在转折，但肉眼难以直接观察。在生产实践中，定植后通常以**第一花序现蕾（现大蕾）**作为樱桃番茄进入生殖生长阶段的可见形态标志。当第一花序现大蕾时，植株进入开花坐果期，标志着番茄「由营养生长为主过渡到生殖生长与营养生长并进」的时期，也是栽培管理的关键转折期。

## 各生育阶段

### 幼苗期

定植后的 15 天内要进行控水炼苗，促进幼苗根系下扎。定植初期，番茄叶片小、叶数少、根系浅，蒸腾量低，需水量少，所以炼苗时间长短主要取决于土壤的田间持水量，土壤性质越是偏沙土的，持水量越低，炼苗时间则越短，相应的越是粘土，炼苗期则较长。

### 开花坐果期

第 16 天左右开始进入开花坐果期，从现蕾到第一穗花序开花为花芽分化的关键时期，生殖生长逐渐旺盛，此时要及时控旺，平衡好营养生长与生殖生长的关系。管理上要促进根系下扎，促进花芽分化，减少花败育、果实败育的情况，提高有效花序数、坐果数，才能实现增产。

可用生物刺激素（腐植酸）+ 高磷性水溶肥 / 磷酸二氢钾 2kg，生根壮苗。叶面营养补充可用氨基酸 + 酶制剂/小分子营养肥（如优马修复剂）+ 钙硼。

### 膨果期

坐果后到开始转色为膨果期，要促进果实发育，使尽可能多的果实健康发育膨大，减少僵果、小果。要注意喷花时间的把握和操作方法，既不能早也不能迟，并且关注气候变化，调整喷花药配方。

建议施肥方案：平衡肥 2.5kg + 微生物菌剂 5～10kg + 钙 3～5kg。

### 转色期

果实开始转色到成熟为转色期，这段时期要注意施肥偏向高钾肥，叶面肥也选择一些促进转色和糖分积累的产品。

建议施肥方案：平衡肥 1.5kg + 高钾肥 1.5kg 或 平衡肥 2kg + 磷酸二氢钾 1kg，二者择一配合钙肥 3～5kg + 腐植酸 5～10kg（土壤调理剂 20kg）。

### 成熟收获期

果实转色至成熟后，满足采摘条件即可采收，通常在 1 穗果成熟比例达到 50% 即可开始采收。第一穗果采摘后，要调整施肥策略，以平衡肥搭配高钾肥灌溉。

建议施肥方案：平衡水溶肥 1kg + 高钾水溶肥 2kg + 水溶有机肥 5kg，钙肥 3～5kg / 微量元素 0.5～1kg（交替使用）间隔 3～5 天，采果后期根据长势及番茄挂果量调整高钾水溶肥用量到 5～10kg/次。

### 摘心期

达到预期花穗数后即可封顶，从封顶到拉秧这段时期为摘心期，通常主干可达 10～12 穗。最顶部花穗上方留两片叶，上方嫩芽直接掐掉，摘心后 5～7 天喷施花果安控旺药剂。

## 灌溉施肥总体节奏

在灌溉施肥管理上，根据温度、气候、土壤质地、田间持水量等情况调整策略，每次灌溉以垄内湿润为准，使用土壤湿度张力计来计算准确用水量、蒸发量，不能单纯以灌溉时间来计算灌溉量。

- 第 1、2 穗果坐果期：7～10 天给水肥一次
- 3 穗果之后：根据温度、光照条件 5～7 天给水肥一次，少量多次施肥
- 封顶前一月：根据温度、气候情况水肥供应次数调整为 7～10 天一次
- 封顶后：根据温度、气候及采摘情况 10～15 天一次或停止水肥供应

采果前期施肥以平衡肥、高钾肥交替使用或平衡高钾配合使用，提高钾元素比例。采果中后期要促进果实转色增糖，施肥以高钾肥为主。每次施肥需配施改良土壤或者生根养根类的有机水溶肥。

## 提高产量的三个关键要素

要提高产量，需要注意花败育、裂果两个问题，结果率决定了产量上限，而裂果是最终产量的主要减量因素。其中花穗形成比率和每穗花数量共同决定了花序形成率，花穗形成比率即是一个生长周期内共计可收获几穗果，控旺良好的情况下，越夏茬可达到 10～11 穗果。

在作物生长过程中，共有 3 个关键要素要注意控制调节：

1. **提高花序形成率**：首先提高花穗形成比率，控制作物生长速度，防止根系早衰，延长生长周期，尽可能收获多的穗数。另外要减少花败育，在作物由营养生长转向生殖生长后，要在营养和环控上促进作物根系发展的同时，促进花芽分化，提高初始花量，为授粉做准备。

2. **降低果实败育率**：果实败育率来源两方面，一是授粉不良、花败育导致没有坐果，二是授粉成功但是果实还没有膨大就掉了，即果实败育，两种情况合起来就是俗称的落花落果。所以在作物开花后授粉期间，要通过人工授粉或熊蜂授粉的方式，尽可能使多的花授粉成功，给予作物适宜授粉的环境条件，以减少落花落果。

3. **提高果实发育率**：果实生长到果实成熟，这段时期果实发育膨大，完成转色，糖度积累，商品性合格的果实数占总果实数的比例即果实发育率。这段时期重点要促进果实转色和糖度积累，风味口感的提升。
