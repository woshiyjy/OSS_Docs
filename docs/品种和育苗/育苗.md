# 育苗

## 种苗标准

番茄从播种到满足种植条件即 4 叶 1 心，在不同的季节气候下发育时间会有所差异，一般冬季育苗周期 38～40 天，其他季节育苗周期在 28～30 天。育苗是生产计划的第一步，而幼苗质量可占产量与品质影响程度的 **70%**，所以要严格控制幼苗质量，预防弱苗、老苗、病苗等问题。

### 一级苗

- 茎粗 ≥ **3mm**
- 根系活力（TTC 法）≥ **0.8**
- 通过近红外光谱检测糖度潜力

### 二级苗

定向供应非高端市场，分级标签需在溯源系统中明确标注。

## 育苗至定植前流程

定植前先分苗：

1. 首先将**好苗与坏苗**区分开，不符合定植要求的坏苗应及时清理
2. 将长势一致的种苗（一级苗）集中摆放，可以直接定植
3. 发育慢的种苗（二级苗）并不意味着是差苗，有可能是育苗时摆放位置温度不同、浇水肥时边际效应等原因导致的长势差异，这部分二级苗暂时另外集中摆放，待达到种植条件后再定植
4. 尽量将**一级苗与二级苗分开定植**，便于后期统一管理

如果遇到特殊情况不能如期定植，要提前与苗场沟通进行控旺，避免苗子过大，开花后移栽不利于田间栽培管理。
