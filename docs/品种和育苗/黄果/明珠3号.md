# 明珠3号（冠蔬茗珠3号）

> **名称说明**：明珠3号即《中宁越夏小番茄种植手册》（3.11）所载"**冠蔬茗珠3号**"（中宁手册将其列入"未来计划测试品种"），本页为该品种信息的唯一落点。

日本进口杂交一代**黄色**樱桃番茄，无限生长型。

## 品种主要性状

- **植株**：长势旺盛，中熟
- **果实**：果形美观整齐，成熟果**金黄色**，圆形，果面光滑
- **单果重**：**18～25 克**
- **坐果**：连续坐果能力强，花量大，产量高
- **口感**：果实硬度好，肉质细腻，**脆甜风味**，口感佳
- **糖度**：可溶性固形物可达 **9% 以上**

## 抗病性

- 含 **ty(1,3a)** 基因点位
- 抗**根结线虫**
- 抗**烟草花叶病毒**
- 中抗**细菌性斑点病**
- 中抗**叶霉病**
