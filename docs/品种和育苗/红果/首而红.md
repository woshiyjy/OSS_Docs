# 首而红

首尔红（首而红）是釜山88系列的衍生品种。本质上是对釜山88进行了**抗性改良**，解决了釜山88最关键的短板——TY病毒抗性。

## 与釜山88的对比

| 维度 | 釜山88 | 首而红 |
|------|--------|--------|
| TY病毒抗性 | 无 | **有** |
| 产量 | 基准 | **高 10～20%** |
| 糖度 | 9～13 度 | 与釜山88相当 |
| 风味浓郁度 | ★★★★★ 红果最佳 | 较釜山88差 |
| 裂果 | 易裂 | 易裂（继承） |

## 核心特点

### 优点

1. **抗 TY 病毒**：解决了釜山88不抗TY病毒的最大短板，扩大了可种植的茬口窗口和产区适配性。
2. **产量更高**：产量比传统釜山88提升 **10%～20%**。
3. **甜度够**：糖度水平与釜山88相当。

### 缺点

1. **风味不如釜山88**：虽然甜度够，但风味浓郁度明显不及原种釜山88。
2. **继承了裂果特性**：釜山88基因中的易裂果特点没有得到改善。

## 品种定位

首而红是典型的"抗性改良型"品种：牺牲了一部分风味，换来了TY病毒抗性和更高的产量。目前是**红果外围产区的主推品种**之一，与鸿运九九并列为釜山88的两大替代品种。核心产区（如对风味要求高的市场）仍偏好原种釜山88。
