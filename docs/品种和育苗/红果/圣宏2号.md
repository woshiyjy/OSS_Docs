# 圣宏2号

圣红2号（圣宏2号）是一个与高丽红相似的红色口感番茄品种，主要定位在**山东产区**，其他产区不作为主推品种。

## 核心特点

### 与高丽红的对比

- 圣红2号与高丽红**很多地方相似**，优点是高丽红有的它基本都有。
- **抗性比高丽红还要好一些**：这是圣红2号相对高丽红最突出的优势。

### 抗高温

- 圣红2号以**抗高温**特性见长。
- 不过以现阶段观察，高丽红的耐高温性状表现也还好，所以这一优势的差异化在缩小。

## 品种定位

- **山东产区主推品种**，其他产区不主推。
- 可视为高丽红的"抗性增强版"：风味糖度接近，但整体抗性更强。
- 适合山东产区的高温环境和重茬种植条件。
