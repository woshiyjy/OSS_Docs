# 鸿运九九

鸿运九九是釜山88系列的衍生品种，与首尔红并列为釜山88的两大抗性改良版本。本质上是对釜山88进行了**抗性强化**，解决了釜山88最关键的短板——TY病毒抗性。

## 与釜山88的对比

| 维度 | 釜山88 | 鸿运九九 |
|------|--------|----------|
| TY病毒抗性 | 无 | **有** |
| 产量 | 基准 | **高 10～20%** |
| 糖度 | 9～13 度 | 与釜山88相当 |
| 风味浓郁度 | ★★★★★ 红果最佳 | 较釜山88差 |
| 裂果 | 易裂 | 易裂（继承） |

## 核心特点

### 优点

1. **抗 TY 病毒**：解决了釜山88不抗TY病毒的最大短板，显著扩大了可种植的茬口窗口和产区适配性。
2. **产量更高**：产量比传统釜山88提升 **10%～20%**。
3. **甜度够**：糖度水平与釜山88相当，满足市场对甜度的要求。

### 缺点

1. **风味不如釜山88**：虽然甜度够，但风味浓郁度明显不及原种釜山88。
2. **继承了裂果特性**：釜山88基因中的易裂果特点在鸿运九九上没有得到改善。

## 品种定位

鸿运九九与首尔红是釜山88的两个平行的抗性改良版本，特性非常接近。两者都是目前**红果外围产区的主推品种**，在核心产区之外大量替代了原种釜山88。对于追求产量稳定性和茬口灵活性的种植者，鸿运九九是比釜山88更安全的选择；对于追求极致风味的市场，原种釜山88仍然是不可替代的。

## 补充性状（来源：宁夏种植手册）

- **果实特征**：着色及光泽好，**耐裂，耐贮运**。平均糖度 10 度，酸甜适中，果皮无残留，口感优秀。
- **抗病性（手册记录）**：抗番茄花叶病毒、番茄黄化卷叶病毒（TYLCV）、斑萎病毒（TSWV）、叶霉病、灰叶斑、根结线虫。抗性谱系宽广。
- **栽培要点**：
  - 提高坐果率，应勤施追肥；中后期增施钾肥，促进着色及提高糖度
  - 根腐病发生地，应选用抗病砧木嫁接栽培
  - 适当降低激素浓度，防止出现畸形果
  - 定植前后注意防治粉虱、蓟马，防止 TY 及斑萎病毒
- **宁夏定植时间**：冷棚 4 月中旬，露天 5 月上旬
