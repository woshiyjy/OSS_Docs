# 品种和育苗

口感番茄品种分类与特性介绍。

## 红果
- [釜山88](红果/釜山88.md) - 韩国引进的红色口感番茄品种，风味浓郁度红果最佳
- [鸿运九九](红果/鸿运九九.md) - 釜山88衍生品种，抗TY病毒，产量提升10-20%
- [玲珑蜜](红果/玲珑蜜.md) - 中早熟红果，鸡心形，糖度10-12度，高抗叶霉病
- [首而红](红果/首而红.md) - 釜山88衍生品种，抗TY病毒，外围产区主推
- [高俪红](红果/高俪红.md) - 非釜山88亲本，风味接近老釜山88，耐裂性红果最高
- [圣宏2号](红果/圣宏2号.md) - 与高丽红相似，抗性更好，山东产区主推
