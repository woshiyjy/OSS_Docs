# 青甜（青甜2号）

青甜（青甜2号）是一个早熟无限生长型樱桃番茄品种，成熟果为绿色带黄，以极高糖度和浓郁番茄味著称。**果皮异常薄嫩，防裂果是管理中的核心难点**。

## 品种主要性状

- **熟性**：早熟，无限生长型，植株长势较为健壮
- **果实特征**：圆形带尖，成熟果为绿色带黄，偶有红丝，色泽温润，外观别致
- **单果重**：约 **20 克**左右
- **坐果**：单穗结果约 15 个
- **口感**：果皮薄嫩，肉质细腻，汁水丰沛，番茄味浓郁，口感香甜无酸味
- **糖度**：可达 **13 度以上**，顶部果实糖度更高
- **抗病性**：抗番茄黄化曲叶病毒病（TY）等常见病害

## 核心难点：防裂果

青甜的果皮异常薄嫩，在以下情况下极易发生裂果：

- 温差过大
- 浇水不均
- 营养补充不足

**裂果是青甜管理中的核心难点**，需要在水肥、环控上做到精细化、稳定化管理。详见 [防裂方案](#防裂方案) 章节。

## 主要栽培措施

- **控旺**：适当控制植株长势，防止徒长
- **基肥**：以有机肥为主，适度增加微量元素肥和补充钾素肥料，着色更靓丽、品质更好
- **授粉**：最好采用**人工和蜜蜂授粉**相结合的方式
- **水分管理**：保持土壤湿度稳定，避免干湿剧烈变化
