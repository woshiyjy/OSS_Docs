# 口感番茄知识库

口感番茄（高附加值樱桃番茄）种植技术知识库，以**产区手册**为主体、通用知识为支撑。

## 知识板块

- **[品种和育苗](品种和育苗/)** - 口感番茄品种卡（红果/黄果/绿果等）与育苗
- **[基础条件](基础条件/)** - 设施类型、栽培类型、水系条件、劳动力管理
- **[种植手册](种植手册/)** - 产区手册：宁夏海原越夏（核心产区）、宁夏中宁越夏、山东基质
- **[植保](植保/)** - 配药控旺、病害、虫害、熊蜂安全用药
- **[采后处理](采后处理/)** - 采后处理技术规程：预冷、分选、包装、贮运、质量
- **[产区和茬口](产区和茬口/)** - 产区、茬口、价格趋势、产业模式
- **[工具模板](工具模板/)** - 问答模板、种植计划模板、ROI 分析模板

## 核心产区

**宁夏海原**（小拱棚越夏茬口）为当前核心产区，手册底本为《海原小番茄越夏茬口种植管理手册》（20260704 正式版）。

## 知识来源

- 《海原小番茄越夏茬口种植管理手册》（20260704）
- 《中宁越夏小番茄种植手册》（3.11）
- 《山东产区基质栽培种植手册》（及地良品基质种植作业指导书）
- 《宁夏樱桃番茄采后处理技术规程》
- 于利宁晨会讲话整理（品种与劳务管理）
