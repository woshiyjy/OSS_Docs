本知识库遵循 [OKF（Open Knowledge Format）](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md) v0.1 规范构建——所有文档以 Markdown 文件 + YAML frontmatter 形式存放，可同时被 VitePress 渲染为网站、被 AI Agent 直接消费。
