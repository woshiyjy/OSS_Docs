# 土地整备

首先收集不同种植主体基地土壤，分类统计土壤成分、EC 及 pH 等，划分土壤类型，依据不同土壤类型对植物根系的影响，建立对应的灌溉标准。海原基地土壤检测详情见 [选址与茬口](选址与茬口.md)。

## （一）设施消杀

对于连年重茬种植的保护地，易出现土传病害、害虫世代增高等问题，可在定植前全棚喷施清园药剂。清理基地周边杂物，将种植环境收拾整洁、干净、整齐。定植前清除杂草、残留作物残体等。尤其注意要（原文本句至此未完）。

## （二）种植区规划

在生产开始前，要合理规划种植区分布面积，为生产路预留好位置，其主要用于采果运输及植保打药机进入。通常滴灌系统一条分管承担灌溉的小区面积为 3-4 亩左右，过大可能地块远端水压不足浇水不匀，过小则生产路面积太大浪费土地。

海原县的拱棚栽培选择在中间，或近门一侧预留生产路，通常 1m 足够，若设施肩高太低，生产路要适当加宽，原则上要人进出方便，避免磕碰头顶。

## （三）深翻深耕

在定植前 1 个月对土壤进行深翻作业，通常土壤板结严重地块通过深翻可以破除犁底层，改良土壤结构，深翻深度约 30cm，沙性土壤深翻深度约为 20cm。翻土可以改善土壤的透气性和排水性，有利于根系的健康生长。

## （四）施基肥

深翻作业结束后要施足基肥，基肥种类包括蚯蚓肥、复合肥、中微量元素等，依据不同土壤类型配置各类基肥用量，对于存在地下害虫的地块，应另外添加杀虫剂。将配置好的各类基肥混合均匀，按照亩用量使用撒肥机均匀撒施到种植区，撒施结束后，使用旋耕机开始旋地，将土地平整，以确保水分和养分的均匀分布。通常旋耕深度在 20-25cm，旋耕 2 遍。

### 1. 有机肥

有机肥根据主要作用的不同有两个选择方向：

- **高碳氮比**：通常至少 25:1，碳氮比高的肥料（如蚯蚓肥、秸秆等）主要作用是改良土壤结构，促进根的生长，抑制茎叶的生长。施用这类肥料可以改善土壤结构，增加土壤有机质含量。选用碳氮比高的富含粗纤维有机肥，可促进根系生长，抑制茎叶生长。
- **低碳氮比**：碳氮比 13:1 或更低，碳氮比低的肥料（如猪粪尿、鸡粪等）主要作用是供应养分，促进茎叶的生长，抑制根的生长。这类肥料适合快速提供植物所需的营养。

应根据土壤类型的不同，确定土壤改良的方向，定制不同本土化有机肥。

### 2. 复合肥

常用 N-P-K 比例为 15-15-15 的缓释或控释型肥料，每亩施用 25-50kg。海原地区要增加复合肥用量，偏控释，持续时间长的。

### 3. 中微量元素

要注意硅、钙、镁、硫肥的补充。通常亩施钙质肥料 20-25kg，硫元素 5kg，可以较好的提高抗病性和品质。

镁肥可根据植株长势和叶片表现，通过硫酸镁等方式补充，以维持叶片功能和光合作用；硅肥可作为提升植株抗逆性、增强茎秆韧性和提高抗病能力的辅助措施，宜选择水溶性或易吸收型硅肥。

微量元素方面，检测结果显示有效锌偏低，同时铁、锰等元素在偏碱性钙质土中也存在有效性不足风险。后续应重点关注新叶黄化、生长点发育弱、叶片失绿等缺素表现，并根据植株长势适量补充锌、铁、锰等微量元素。微量元素建议优先采用螯合态产品或叶面喷施方式，少量多次补充，以提高吸收效率并降低土壤固定风险。
