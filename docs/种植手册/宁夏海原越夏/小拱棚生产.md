# 小拱棚生产

## （一）起垄

**方案一（单行密植）**：株距 15cm，4000 棵/亩，双干整枝。垄高 20cm，种植行宽 50cm，操作行 100cm。前期不需要覆膜，待缓苗后吊蔓后再覆膜。采用普通银灰防草膜，膜不需打孔，宽 40cm，防草膜铺在定植行两侧，隔 2m 铲少量土压一下，两道膜中间用竹签插住固定。

**方案二（双行定植）**：株距 25cm，3800 株/亩，双干整枝。垄高 20cm，种植行宽 60cm，操作行 80cm。起垄后直接覆膜，使用银灰防草打孔膜，两端铲土压住，中间压一下。

## （二）安装滴灌

在定植前安装滴灌系统，以保证定植后的水分供应。主管不要铺设在生产路上，避免影响过路，尽量摆在生产路对侧，垄面尽头。

地下水位高、土壤粘性重，种植面积小，选择 15cm 单孔滴灌带；地下水位低，沙性土壤，种植面积较大选择间距 20cm 双孔滴灌带。土壤保水性差，光照强度大的种植区域，可再加装一条滴灌带，带阀门开关，需水量大时打开开关，需水量小时关闭。

滴灌带孔朝上，避免泥土堵塞。滴灌带一端连接旁通阀，另一端铺到垄面尽头后绕过植株转回主管，再连接旁通阀，不需要剪开分别铺设。

## （三）定植

### 1. 定植前准备工作

观察好移栽前 7-10 天的天气，选择连续晴天的早晨进行移栽，避开低温天气，确保平均温度稳定在 10°C 以上再定植。定植时也要避开极端高温，尽量不要超过 35 度，否则跟水不及时幼苗易脱水至死，或被薄膜与幼苗茎基部接触位置高温烫断茎杆至死。

根据既定定植计划，配置相关人员，通常包括：1 名现场管理人员负责监督定植及浇水；1 人蘸根，1 人散苗，28 人栽苗，散完苗后同时移栽。每人每日移栽数约为 3500-4000 棵。

准备好定植定距绳、挖土铲子；工具包，携带剪刀，滴灌系统各类相应接头，灌溉时及时修补水管。药泵、药桶，车辆（油满，电满）、蘸根水盆，取水源水泵等。准备备用水泵，备用电源，以及灌溉设施各类配件，重点防止水泵、电源故障。

### 2. 备苗

在定植前一天的傍晚，将需要移栽的种苗转运到定植现场并妥善存放，重点防止冷空气侵袭。若没有存放条件，尽量提前一天装好车，第二天定植前提前运到现场。没有定植的种苗一律放在转运箱中不要取出。

- **在阴凉通风处存放**：选择阴凉、通风良好的地方存放幼苗，避免阳光直射和风吹，以防止幼苗因高温或脱水而受到伤害。存放地面应平整、干燥，避免积水或湿滑地面，防止幼苗根部长期浸水或受潮。
- **转运箱保持一定间隔并避免堆叠过高**：幼苗在现场存放时应避免堆叠过高，以免下层苗木受到挤压，导致茎叶损伤或根系缺氧。摆放幼苗时应留有适当间隙，确保每株幼苗都有良好的通风环境，减少病菌传播的风险。
- **长期未移栽遇高温要及时喷水防止种苗脱水萎蔫**：定植前要在苗场给苗子补足水分，另外在定植期间，如遇存放时间较长，应适时对幼苗进行喷水，保持叶片和根部的适宜湿度，但避免过度浇水造成土壤积水。在干燥环境中存放时，可在存放区域洒水，增加空气湿度，防止幼苗因环境干燥而萎蔫。

### 3. 定植

做好定植前准备即可开始定植。若使用打孔膜，可直接在孔内栽植，不使用打孔膜的，要人工使用定距绳定好株距。

负责蘸根的人要提早配好蘸根水，使用略大于穴盘的平底框，至少 4 个，内部盛水量与穴盘持平即可，再用水桶多配一些蘸根药，平底框蘸根水用完后随时添加。将穴盘放于框内，大约 10s 穴盘内基质即可吸上水，而后由散苗人员提走散至垄上即可。

人员进入大棚内时，每人拎一盘蘸过根的穴盘苗，根据起垄长短每 1 垄或 2 垄放一盘苗，而后每人就近栽两垄开始栽苗。

首先，使用小铲子挖开栽植坑，深度以将苗子放入坑内后基质坨比垄面低 1cm 左右为宜，通常底深 7cm 左右。之后，提苗放入栽植坑，提拿苗子中部叶片节间，轻拿轻放。最后，从垄面上取土填满栽植坑，双手掌平着按压苗子周边以压实土壤，不可用手指向下按压基质坨，覆土厚度超过基质坨 1-2cm 厚左右即可。禁止放苗及覆土时以手指用力按压基质坨，防止破坏基质坨完整损伤苗子根系。

对于分苗后的二级苗，若存在高脚苗情况，定植时尽量斜栽、深栽，这样茎基部的气生根也可以在适宜环境下生根下扎。

### 4. 定植水

每个小区栽完后就立即开始浇水，以防苗子受到干旱胁迫，脱水萎蔫。浇水时确保水流顺畅，避免滴灌带孔眼堵塞、被铲子划破等。浇水标准为整个垄上面及侧面都被水洇湿，控制灌溉时间，不需过度灌溉。灌溉时随时巡查滴灌带间距，离苗较远的及时调整，确保根系及时补水。

### 5. 缓苗水

定植后 5-7 天，根据土壤湿度及气候情况小水补充，配合使用生根剂，保持垄内湿度，促进生根及根系伸展。

## （四）调整吊蔓钢丝

- **调整钢丝**：每条垄上方有两道钢丝，一般为 18-20 号钢丝，在定植约 3-5 天后垄沟干透，就开始调整钢丝间距，使两道钢丝在种植行正上方，相邻间距为 40cm；
- **绑吊蔓绳**：吊蔓绳高度要从钢丝上方自然下垂至地面，通常高度 220cm，系活扣绑在钢丝上，根据种植行株距调整吊蔓绳间距；按照留头数准备吊蔓夹。

## （五）压苗

将相邻番茄苗顺垄一棵向左，一棵向右压倒，不要大力按压损伤茎秆。对已近倒伏的种苗，不要强行进行左右压苗作业。压苗操作一是可以使番茄苗茎部弯折更有韧性，方便后续吊蔓作业，二是还可以通过弯折茎蔓，抑制顶端优势，使双干或三干长势整齐。

## （六）授粉

### 1. 人工授粉（喷花）

喷花仍是大棚普遍采用的授粉方式，其原理主要是通过激素作用花柄离层，延缓离层成熟速度，防止落花落果，同时诱导番茄单性结实，以此来达到坐果、膨果的目的，常见配方见表。

**表. 人工喷花配方**

| 商品名 | 成分 | 用量 g/ml |
|--------|------|-----------|
| 保果素 | 2 克得灵 | 甲硫·乙霉威 1 |
| 常萼灵 | 2 | 5-30 |
| 易发 | 氨基酸 | 15 |
| 聚能钙 | 补钙 | 20 |
| 兑水量（L） | | 11 |
| 喷花时期 | | 开花 5-7 朵 |
| 喷花频率 | | 5-7 天/次 |
| 喷花温度 | | 18~28°C |
| 工具 | | 小型手动喷花器/电动喷花器 |

> 注：本表为原文表格重建，列位对应关系以原手册表格为准。

喷花注意事项：

（1）每穗花通常喷两次，第一次在花开一半后（约 5-7 朵）开始，第二次等花序其余小花开放后开始，通常两次喷花操作间隔 5-7 天。喷时期不宜太早，否则花量少，喷花后即坐果，此时少量果实会抑制该穗花其他小花的坐果，形成果重差异巨大的大小果；

（2）喷花时应避开生长点，喷在花序背面离层位置；

（3）若存在落果现象可以添加 1ml 赤霉素/萘乙酸钠；

（4）喷花前 1-2 天喷一次微量元素（花喜 1500 倍）可显著提高坐果率和商品率。

### 2. 熊蜂授粉

熊蜂授粉是当前在小番茄种植中逐渐流行的一种授粉方式，优势明显，相比于人工喷花更省工，坐果率更高，同时因为熊蜂授粉的番茄属于授精结实，所以子房内会有饱满的种子，番茄风味更浓郁。熊蜂减少了激素的使用量，植物长势更健康，食用也更安全。

熊蜂使用时应严格遵照厂家的使用说明及植保用药要求，避免人为导致的熊蜂批量死亡。每只熊蜂单日访花量可达 3000 朵，但会存在重复访花的情况，通常每亩地投放 1 箱 120 头左右蜂群即可。在 1 穗花有 2-3 朵小花开放后即可投放熊蜂，投放后要随时观察授粉情况，授粉成功的花朵雄蕊上可看到褐色吻痕。熊蜂投放不能太早，因为前期花量少花粉少，熊蜂缺少食物来源可能过度授粉。

**熊蜂授粉与减药增效**：强制使用熊蜂授粉（替代人工喷花），配套措施：植保用药严格遵循 [熊蜂安全用药指南](../../植保/熊蜂安全用药指南.md)；每棚配置蜂箱活性监测仪，温度超 28°C 自动启动遮阳喷雾降温。

**表. 人工喷花与熊蜂授粉对比**

| 对比项 | 人工喷花 | 熊蜂授粉 |
|--------|----------|----------|
| 成分 | 激素：植物生长调节剂 | 无 |
| 果实特征 | 多为单性结实无种子，萼片厚、长，花瓣在萼片与果柄位置脱落 | 有种子，萼片薄、短，花瓣在柱头位置脱落 |
| 授粉率 | 70%-100% | 100% |
| 产量损耗 | 工人工作质量差，漏喷座果率低，重喷畸形果 | 蜂箱转移过程中未归巢熊蜂损失，工蜂减少影响座果率 |
| 优势 | 萼片更厚更大 | 座果率高，坐果均匀，无激素 |
| 劣势 | 人工成本高，管理成本高，座果率不稳，受气候影响大 | 植保协调管理难度高，包括用药、蜂箱的转移和存储成本 |
| 费用 | 7 天/次，共 975 元（13 次，75 元/亩·次） | 一箱蜂连续使用 45-60 天，共 700 元（2 箱） |

收到熊蜂后，要及时打开自带的糖水壶，组装蜂箱通风系统，检查熊蜂活性。熊蜂的生活温度为零上 6 到 32 度，适宜的工作温度为 16-28 度，因此在棚内摆放蜂箱时，夏季应摆放在阴凉通风处，注意在蜂箱顶部做好遮荫。要避免蚂蚁等爬进蜂箱，可采用悬挂摆放或在水盆中支架摆放的方式隔离。

熊蜂授粉特别注意事项：

（1）**温度**：5-35°C 下可正常工作，低于 5°C 停止工作，超过 35°C 会中暑死亡；

（2）**食物**：熊蜂以花粉和蜜为食，番茄没有蜜腺，所以蜂箱要配置糖水盒，通常自带的糖水盒足够熊蜂 45-60 天的使用时间，而番茄的花粉足够为蜂箱中的成蜂与幼蜂提供食物，所以不需要补充花粉；

（3）**严格遵守植保原则**：打药前转移蜂箱，打药后达到安全间隔再放回蜂箱（详见 [熊蜂安全用药指南](../../植保/熊蜂安全用药指南.md)），蜂箱保存在阴凉通风条件下。

易出现蜂蜇的情况：（1）暴力拍打蜂箱，导致被蜇；（2）经常贴近蜂箱，惊扰熊蜂，导致被蜇；（3）用手拍打飞行中的熊蜂，导致被蜇。

预防蜂蜇的措施：（1）熊蜂对于酒精、香水、肥皂、须后水等气味和蓝色较敏感；（2）蜂蜇处通常会肿起，肿处红痒，仅持续数小时。如为过敏体质或蜂蜇发生于人体敏感处时（如眼睛附近），一般建议遵医嘱服用药物，并用冰袋冷敷蜂蜇部位。

### 3. 定蔓

双干整枝，均留第 1 穗花序下真叶腋芽做副头（弹弓叉）。将底部贴地的两片底叶打掉，除主干副干外的侧枝均打掉。

### 4. 吊蔓

吊蔓前顺好钢丝绳和吊蔓绳，钢丝绳两行相距 40cm，与植株上下相对平行。使用吊蔓夹吊蔓，选择一穗花下方茎干粗壮处位置，夹在叶柄基部茎杆上，利用茎杆和叶柄、绳子形成三角稳定结构以稳定植株。根据植株卧倒情况吊，不要刻意拉提吊秧。吊蔓绳不能交叉、缠绕，与植株垂直。

### 5. 绕蔓

拱棚绕蔓与打杈要同时进行，在蔓长 30cm 左右开始绕蔓，同时将除主副干以外多余侧枝及根部斜杈全部打掉。打杈时一手稳住主干，一手"推杈"或"抹杈"，一定要避免折断主干或撕掉茎杆表皮，否则增加植保风险。要及时绑蔓绕蔓，若操作过晚，主副干侧弯垂落，不利于通风透光，也可能折断，且在日常农事操作过程中阻挡行进，易落花落果。绕蔓时，每两到三穗花间缠 1 圈即可，不能缠绕太多圈拉紧绳子，要给绳子为植株上部继续绕蔓留足长度。
