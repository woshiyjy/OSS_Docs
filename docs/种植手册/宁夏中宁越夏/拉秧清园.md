# 拉秧清园

1. 拱棚先用镰刀砍断秧子根部，待秧子干掉后，回收吊蔓夹、滴灌带，将吊蔓绳每 2 米一段绑束起来；露地把绳子割断，拔掉竹竿，竹竿 50 根一捆，然后存放到指定位置，存放时一颠一倒码放平整，然后打包机清秧处理；

2. 清理秧子、清理薄膜；

3. 深翻晾晒，粘性较重的地块深耕 30-40cm，砂性土壤浅耕 20-25cm；

4. 灌水，大水浇透，利用冬季低温冻死土壤中的虫卵、部分病原菌，并给来年土壤保存一定墒情。
