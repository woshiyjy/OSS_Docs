# 种植手册

本板块按**产区手册制**组织：每本产区手册自成完整体系（选址 → 土地整备 → 灌溉 → 生长发育 → 生产 → 拉秧清园），正文以原手册大段原文为准。跨产区通用知识（品种、育苗、植保、劳动力）收录于对应独立板块。

## 产区手册

### 宁夏海原越夏

**核心产区**。底本：《海原小番茄越夏茬口种植管理手册》（20260704 正式版，海原县农业农村局主编）。

选址与茬口 → 土地整备 → 灌溉设施 → 生长发育（含增糖/防裂方案）→ 小拱棚生产 → 拉秧清园

### 山东基质

底本：《及地良品基质种植作业指导书》。

农事管理 → 水肥管理（含 FAQ）→ 病虫害管理

### 宁夏中宁越夏

底本：《口感番茄·宁夏中宁地区越夏种植管理手册》（3.11）。

选址与气候 → 土地整备 → 灌溉设施 → 生长发育 → 大棚生产 → 露地生产 → 拉秧清园
