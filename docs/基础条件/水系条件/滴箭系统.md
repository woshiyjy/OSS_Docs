# 滴箭系统

滴箭系统是基质栽培的核心灌溉方式，通过压力补偿滴头和滴箭实现精准、均匀的水肥供给。

## 系统组成

```
水源 → 水罐 → 水泵 → 过滤器 → 主管道 → 阀门 → 毛管 → 压力补偿滴头 → 滴箭 → 基质
```

## 核心参数

| 参数 | 标准值 | 说明 |
|------|--------|------|
| 滴箭间距 | **20cm** | 1.2 米基质条插 6 个滴箭 |
| 滴头流量 | **1 升/小时** | 压力补偿滴头 |
| 滴灌压力 | **0.25～0.28 MPa** | 全棚任意滴头处 |
| 单次滴灌时长 | **2 分钟** | 通过频次调整总量 |

## 水罐配置

- 容量：**每亩 4 吨以上**，宜大不宜小
- 2 亩大棚建议配置 10 吨水罐
- 用 **80% 以上遮光网**遮盖，防止藻类滋生

## 水泵选型

- 额定扬程：约 **30 米**
- 额定流量：大于滴灌总流量，宜大不宜小
- 示例：4000 个 1L/h 滴头，总流量 4 吨/小时 → 水泵额定流量须 **＞ 4 吨/小时**

## 主管道配置

- 根据滴灌总流量和主管长度选择管径
- 滴灌总流量越大、主管行程越长 → 主管越粗
- 主管过粗增加成本，过细则大棚两头水压不一致
- 参考：100 米长 2 亩土墙暖棚，主管行程约 110 米 → **50PE 主管**

## 压力补偿滴头

- 流量：**1 升/小时**
- 功能：带**低压防滴漏**
- 品牌推荐：华最、耐特菲姆等知名品牌
- 配合毛管和"8"字堵头使用

## 压力管理

保持全棚任意滴头处压力在 **0.25～0.28 MPa**：

- 通过调节阀门控制管道水压
- 安装过滤器及前后压力表监测压力变化
- 定期清洗叠片过滤器
- 压力不足 → 远端滴灌不均匀；压力过大 → 管道风险

## 回水搅拌溶肥

利用回水冲击力加速肥料溶解：

1. 水罐加满清水
2. 关闭滴灌阀门，打开回水阀门
3. 开启水泵，待水翻滚
4. 依次加入 A、B、C、D 肥
5. 继续保持翻滚 **15 分钟**，让肥料充分溶解均匀

## 自动控制

可设置自动滴灌时间，支持手机远程控制，实现定时定量灌溉。
