# 基质栽培

基质栽培是一种精准水肥管控的无土栽培方式，相比土壤栽培具有水肥利用率高、根系环境可控、避免土传病害等优势。

## 核心原则

> **基质条全程不能控水！** 必须保持饱和状态，每天有渗出液。

控水会导致基质条水层分布不断变化，不利于根系稳定分布及高效发挥功能，甚至会不断破坏已形成的根系。正确做法是：通过调整**渗出液量**来调整基质条内水肥的 EC 值，基质含水量始终保持饱和。

## 核心参数速查

| 类别 | 参数 | 说明 |
|------|------|------|
| 基质条规格 | 宽 20cm × 厚 8.5cm | 小番茄最佳规格 |
| 行距 | 约 1.5m | 种植番茄标准行距 |
| 普通品种株距 | 24cm 左右 | 釜山系红色小番茄 |
| 高口感品种株距 | 30cm 左右 | 红情98、358、铭珠3号等 |
| 滴箭间距 | 20cm | 1.2 米基质条插 **6 个滴箭** |
| 滴头流量 | 1 升/小时 | 压力补偿滴头，带防滴漏 |
| 滴灌压力 | **0.25～0.28 MPa** | 全棚管道任意滴头处压力 |
| 水罐容量 | 每亩 4 吨以上 | 宜大不宜小，2 亩棚建议 10 吨 |
| EC 值范围 | 0.75～1.87 mS/cm | 根据生育期调整 |
| 单次滴灌时长 | 2 分钟 | 通过调整频次控制总量 |
| 滴灌时段 | 白天 8:00-17:00 | 晚上不滴灌 |
| 遮阴温度阈值 | 35℃ 以上 | 每天遮阴不超过 5 小时 |

## 种植布设

### 起垄要求

- 根据大棚雨季淹水风险确定起垄高度
- 铺设基质条前须将垄面**整平压实**
- 防止基质条摆放不平导致水肥分布不均匀

### 隔离膜

- 基质条下方垫塑料膜，隔离土壤
- 膜厚度：**7 丝以上**
- 膜幅宽：80 公分左右

### 定植孔

使用自制锥形头打孔工具，按压基质即可成孔，孔尺寸与育苗盘穴孔近似。

### 滴箭布置

- 滴箭间距 20cm，1.2 米基质条插 6 个
- 滴箭过于稀疏会导致水肥分布不均匀

## 渗出液管理（关键）

保证基质条每天都有渗出量的原因：

1. **防止盐害**：防止盐分不断积累。灌溉用水盐度越高，盐分越容易积累，所需渗出量越大。
2. **稳定根系环境**：保持基质含水量及水分分布量稳定，保障根系稳定及其高效吸收水肥的能力。

## 定植操作

### 定植前

- 定植前 1～2 天，用营养液将基质条滴灌饱和
- 检查滴灌系统是否正常工作，每个滴箭出水均匀
- 提前将苗从苗床取出炼苗适应环境

### 定植方法

1. 用锥形头打孔工具按压成孔，孔深与育苗盘穴孔深度相当
2. 将苗从穴盘轻轻取出，注意保护根系完整
3. 放入定植孔，轻轻按压周围基质使根系与基质紧密接触
4. 深度以基质覆盖到苗的根茎交界处为宜，不宜过深或过浅
5. 定植后**立即滴灌**一次，确保基质与根系充分接触

### 定植后

- 3 天内注意遮阴，避免强光直射造成萎蔫
- 及时检查缓苗，发现死苗及时补苗
- 缓苗后（约 5～7 天）开始正常水肥管理
- **定植最佳时间**：阴天或晴天下午，避免高温时段

## 与土壤栽培的关键区别

| 维度 | 土壤栽培 | 基质栽培 |
|------|----------|----------|
| 水分管理 | 可控水炼苗 | **全程不控水**，保持饱和 |
| 水肥供给 | 间歇式灌溉 | 高频少量滴灌（2分钟/次） |
| 根系环境 | 土壤缓冲性强 | 基质缓冲性弱，需精准管控 EC |
| 盐分风险 | 较低 | 需通过渗出液防盐害 |
| 适用茬口 | 以越夏为主 | 秋延+越冬+春延长周期连续生产 |
