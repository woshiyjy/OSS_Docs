# 宁夏产区小拱棚越夏茬口种植

## 总体原则

根据温度、气候、土壤质地、田间持水量等情况调整策略：
- 每次灌溉以**垄内湿润**为准
- 使用土壤湿度张力计计算准确用水量、蒸发量
- **不能单纯以灌溉时间计算灌溉量**

## 各生育阶段水肥方案

### 幼苗期（定植后 1～15 天）

**控水炼苗**，促进根系下扎。定植初期叶片小、叶数少、根系浅，蒸腾量低，需水量少。

- 炼苗时间取决于土壤田间持水量：沙土短，黏土长
- **定植水**：每个小区栽完后立即浇水，标准为整个垄面及侧面被水洇湿
- **缓苗水**：定植后 5～7 天，小水补充，配合生根剂

### 开花坐果期（第 16 天起）

从现蕾到第一穗花开花，生殖生长逐渐旺盛，需及时控旺，平衡营养与生殖生长。

**施肥方案**：
- 生物刺激素（腐植酸）+ 高磷性水溶肥 / 磷酸二氢钾 2kg
- 叶面：氨基酸 + 酶制剂/小分子营养肥 + 钙硼

**灌溉频率**：第 1、2 穗果坐果期 7～10 天给水肥一次。

### 膨果期

坐果后到开始转色，促进果实发育、减少僵果小果。

**施肥方案**：
- 平衡肥 2.5kg + 微生物菌剂 5～10kg + 钙 3～5kg

**灌溉频率**：3 穗果之后根据温度、光照条件 **5～7 天给水肥一次**，少量多次。

### 转色期

**施肥方案（二选一）**：
- 方案A：平衡肥 1.5kg + 高钾肥 1.5kg
- 方案B：平衡肥 2kg + 磷酸二氢钾 1kg

两者均配合：钙肥 3～5kg + 腐植酸 5～10kg（或土壤调理剂 20kg）

### 成熟收获期

1 穗果成熟比例达 **50%** 即可开始采收。第一穗果采摘后调整策略：

**施肥方案**：
- 平衡水溶肥 1kg + 高钾水溶肥 2kg + 水溶有机肥 5kg + 钙肥 3～5kg
- 微量元素 0.5～1kg（交替使用），间隔 3～5 天
- 采果后期根据长势及挂果量，高钾水溶肥调整至 **5～10kg/次**

**灌溉频率**：采果前期平衡肥、高钾肥交替使用。采果中后期以高钾肥为主。

### 摘心期（封顶后）

- 封顶前一月：水肥 7～10 天一次
- 封顶后：10～15 天一次或停止水肥供应

## 增糖方案

增糖从果实膨大后期到转色期逐步调整，不是等果子快熟了才"催甜"。

### 水分：小水勤浇，采前不浇大水

- 果实转色前 **10～15 天**，从"促膨果"改为"稳水提糖"
- 滴灌地块少量多次，晴天每 **2～4 天**小水一次，每次只湿润主要根区
- **采收前 24～48 小时尽量不浇水**

### 肥料：高钾低氮

- 转色期方向：**高钾、低氮、补镁**
- 钾 → 糖分运输和果实风味
- 镁 → 叶绿素和光合作用
- 氮肥过多 → 植株偏旺、果味变淡、糖度下降
- 基肥使用蚯蚓肥有助于糖分提升

### 叶面：磷酸二氢钾 + 镁 + 硼钙

- 转色前后每 **7～10 天**喷一次
- 晴天下午或傍晚喷，避开高温强光

## 防裂方案

裂果原因：果皮生长和果肉膨大速度不一致。前期干旱抑制果皮发育，后期突然浇大水，果肉快速膨大将果皮撑裂。

### 水分：小水勤浇，不可干透再浇

- 保持土壤湿度**稳定**
- 不能为了提糖把地控到过干，更不能控干后一次浇透
- 已连续控水 3～5 天后恢复浇水：**第一水只能小水**，间隔 1～2 天再逐步恢复正常

### 肥料：钙硼硅提前补

| 元素 | 作用 |
|------|------|
| 钙 | 细胞壁组成成分 |
| 硼 | 帮助钙吸收和细胞壁稳定 |
| 硅 | 在表皮和细胞壁沉积形成"加强层"，提高果皮机械强度和弹性 |

- 从**坐果后**就开始补，不是裂果发生后才喷
- 钙和硅在植株体内移动性差，应**根部 + 叶面结合**
- ⚠️ 钙肥不要和磷酸二氢钾、高磷肥、硫酸钾在同一个桶里高浓度混配（会沉淀），可分开冲施或一水高钾、一水钙镁交替
