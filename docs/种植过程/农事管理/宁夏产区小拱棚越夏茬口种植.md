# 宁夏产区小拱棚越夏茬口种植

## 调整吊蔓钢丝

- 定植约 3～5 天后垄沟干透，调整钢丝间距
- 每条垄上方两道钢丝（18～20 号），相邻间距 **40cm**，在种植行正上方
- 吊蔓绳从钢丝上方自然下垂至地面（通常高度 220cm），系活扣

## 压苗

将相邻番茄苗顺垄一棵向左、一棵向右压倒（不要大力按压损伤茎秆）。

**目的**：
1. 使茎部弯折更有韧性，方便后续吊蔓
2. 通过弯折茎蔓抑制顶端优势，使双干或三干长势整齐

已近倒伏的种苗不要强行压苗。

## 授粉

### 人工喷花

喷花原理：通过激素作用花柄离层，延缓离层成熟速度防止落花落果，同时诱导单性结实。

**参考配方（11L 水）**：

| 成分 | 用量 |
|------|------|
| 保果素 | 2g |
| 克得灵（甲硫·乙霉威） | 1g |
| 常萼灵 | 25～30g |
| 易发（氨基酸） | 15g |
| 聚能钙补 | 20g |

**操作要点**：
- 开花 5～7 朵时喷，每穗花通常喷 **2 次**（间隔 5～7 天）
- 喷花温度：**18～28℃**
- 喷在花序**背面离层**位置，**避开生长点**
- 喷太早 → 少量果实抑制同穗其他小花坐果，形成大小果
- 若落果可添加 1ml 赤霉素/萘乙酸钠
- 喷花前 1～2 天喷一次微量元素可显著提高坐果率和商品率

### 熊蜂授粉

熊蜂授粉为**受精结实**，子房内有饱满种子，番茄风味更浓郁，且减少激素使用。

| 对比维度 | 人工喷花 | 熊蜂授粉 |
|----------|----------|----------|
| 成分 | 激素（植物生长调节剂） | 无 |
| 果实特征 | 多单性结实无种子，萼片厚长 | 有种子，萼片薄短 |
| 授粉率 | 70%～100% | 100% |
| 成本 | 975 元/亩（13 次 × 75 元） | 700 元/亩（2 箱） |
| 优势 | 萼片更厚更大 | 坐果率高、均匀、无激素 |
| 劣势 | 人工成本高、受气候影响大 | 植保协调管理难度高 |

**投放与使用**：
- 每亩 **1 箱**（约 120 头蜂群）
- 1 穗花有 2～3 朵开放后投放，不宜太早（前期花量少花粉少，可能过度授粉）
- 单日访花量可达 3000 朵（含重复访花）
- 工作温度：**16～28℃**（5～35℃ 可存活）
- 蜂箱配置糖水盒（番茄无蜜腺），自带糖水足够 45～60 天
- **打药前转移蜂箱**，打药后达安全间隔再放回

**熊蜂安全**：
- 暴力拍打蜂箱、经常贴近蜂箱、用手拍打飞行熊蜂 → 易被蜇
- 熊蜂对酒精、香水、肥皂等气味和蓝色较敏感

## 定蔓

双干整枝：均留第 1 穗花序下真叶腋芽做副头（弹弓叉）。打掉底部贴地两片底叶，除主干副干外所有侧枝均打掉。

## 吊蔓

- 钢丝绳两行相距 40cm，与植株上下相对平行
- 使用吊蔓夹，夹在一穗花下方茎干粗壮处（叶柄基部茎杆上）
- 利用茎杆、叶柄、绳子形成三角稳定结构
- 根据植株卧倒情况吊，**不要刻意拉提吊秧**
- 吊蔓绳不能交叉、缠绕

## 绕蔓

- 蔓长约 **30cm** 开始绕蔓，与打杈**同时进行**
- 除主副干外全部侧枝及根部斜杈打掉
- 打杈时一手稳住主干，一手"推杈"或"抹杈"，**避免折断主干或撕掉茎杆表皮**（增加植保风险）
- 每两到三穗花间缠 1 圈即可，不能缠绕太多圈拉紧绳子
- 操作过晚 → 主副干侧弯垂落不利通风透光，可能折断，阻碍行进

## 摘心

达到预期花穗数后封顶（通常主干可达 **10～12 穗**）：
- 最顶部花穗上方留**两片叶**，上方嫩芽直接掐掉
- 控旺良好的情况下，越夏茬可达 **10～11 穗果**
- 摘心后 5～7 天喷施花果安控旺药剂

## 提高产量的三个关键

1. **提高花序形成率**：控制生长速度，防止根系早衰，延长生长周期，尽可能多收穗数
2. **降低果实败育率**：促进花芽分化 + 适宜授粉环境 + 人工/熊蜂授粉 → 减少落花落果
3. **提高果实发育率**：促进转色、糖度积累和风味提升

## 拉秧清园

1. 拱棚：镰刀砍断秧子根部 → 秧子干掉后回收吊蔓夹、滴灌带，吊蔓绳每 2 米一段绑束
2. 露地：割断绳子 → 拔竹竿（50 根一捆，一颠一倒码放平整）→ 打包机清秧
3. 清理秧子、薄膜
4. 深翻晾晒：粘性重 30～40cm，砂性 20～25cm
5. 大水浇透：利用冬季低温冻死虫卵和部分病原菌，给来年保墒
