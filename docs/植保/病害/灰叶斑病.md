# 灰叶斑病

灰叶斑病由 3 种茎叶真菌引起，叶面病害，只要易感品种生长在温暖潮湿的环境下会带来毁灭性的结果。

叶片症状由不规则的棕黑色小病斑组成，形状可为圆形至椭圆形。病斑中心为灰色，边缘为深棕色至黑色，病斑中心可能开裂。病斑较多或较大的受感染叶片将变黄并脱落。灰叶斑主要影响叶片；即便在最适宜的条件下发病，它也很少影响茎或叶柄。侵染幼苗也会导致落叶，但不会出现任何明显的黄变。虽然这种病害不会直接影响果实，但过早落叶会使果实暴露在阳光和雨水下，导致日晒雨淋。

匍柄霉属影响的杂草和植物种类范围广泛，确保及时销毁田间的植物残体，并对温室内的花盆、工具表面进行消毒，将限制病原体从一种作物传到下一种作物。有效的商业品种抗性，是控制灰叶斑病的主要手段。

## 防治方法

预防可用 75% 百菌清可湿性粉剂 600 倍液等保护性杀菌剂喷雾。治疗药剂可用 10% 苯醚甲环唑水分散粒剂 1500 倍液、25% 嘧菌酯悬浮剂 1500 倍液等喷雾防治。
