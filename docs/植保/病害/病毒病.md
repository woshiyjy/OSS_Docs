# 病毒病

## 粉虱传播的双生病毒——番茄黄化曲叶病毒（TYLCV）

菜豆金黄花叶病毒属是双生病毒科最大的一个属，与该科其他成员一样，它由包裹在准异构病毒粒子内的单链环状 DNA 基因组组成。菜豆金黄花叶病毒可以进一步分为单组分或双组分形式，这取决于它们的基因组是由 1 个还是两个环状的 ssDNA 分子组成。

世界各地的热带和亚热带地区的番茄生产受到许多双生病毒的攻击，与烟粉虱的传播相吻合。一旦感染菜豆金黄花叶病毒属，就会通过粉虱以持续循环的非繁殖方式传播。番茄黄化曲叶病毒（TYLCV）是影响番茄的最重要和最严重的病毒之一。

TYLCV 的典型症状包括受感染植株严重发育不良，节间缩短，顶端和腋芽直立。发育中的叶子无法扩张，形成的小叶体积缩小，形状异常，叶缘极为褪绿，呈杯状向上。那些在幼苗早期就被侵染的植物会严重发育不良不能结实。受侵染后，衰老植株上先结的果实会按期成熟，但随后的果实会变小，并逐渐停止坐果。花朵不受 TYLCV 的影响，但随着症状的加重，花朵会无法受精而脱落。

也许病毒最令人担忧的特征之一是，它们能够通过突变、重组和染色体变异，迅速导致了全球范围内的多样化，能够在全世界引起"卷叶"或"黄叶"症状。另一种被称为番茄斑驳病毒的重要双组分病毒也发生了类似的事件，该病毒也由粉虱传播，但与 TYLCV 不同，它也可以机械传播。已鉴定出几个对 TYLCV 具有抗性的基因，其中一个基因 Ty-1 已用于商业化番茄生产。遗憾的是，对 TYLCV 具有抗性的番茄品种仍然可以被感染并传播病毒（尽管症状大大减轻），成为其他易感植物的病毒宿主。

## 蓟马传播的番茄斑萎病毒（TSWV）

番茄斑萎病毒属于斑萎病毒属，是布尼亚病毒科中唯一可以侵染植物的属。斑萎病毒的基因组由具有负极性的单链 RNA 组成，分为 3 个片段，分别称为小"S"（2.9kb）、中的"M"（5.4kb）和大的"L"（8.9kb），这 3 条 ssRNA 的总大小为 17.2kb。与其他植物病毒相比，斑萎病毒是相当复杂的，因为 3 个 ssRNA 片段中的每一个都被分别包裹在来自寄主植物的膜中。包括 TSWV 在内的所有斑萎病毒成员都是通过蓟马以持续繁殖的方式传播。尽管至少有十种蓟马可以传播斑萎病毒，但西花蓟马被认为是最主要的传播载体，因为它在全球广泛分布，并且能够传播大多数斑萎病毒。

TSWV 的症状可能因病毒株和侵染时番茄植株的年龄而有很大差异。受侵染番茄植株的幼叶出现青铜色，并出现大量的深紫色到黑色小斑点，这些斑点可以合并成条纹延伸到叶柄甚至茎的末端。初期，这些斑点可能看起来有点类似于细菌性疮痂病的新鲜病变。然而，与 TSWV 相关的病斑通常位于叶脉沿线，不穿过叶的两侧。受侵染的植物也可能出现侧边倾斜的生长习性，甚至表现出枯萎的症状。在侵染严重的植物中，生长点可能会死掉，茎的末端会出现条纹。早期感染的番茄植株可能不会发育出果实，但在坐果后受侵染的植株会发育出带有褪绿环斑的果实。在绿色果实上，这些环状斑点通常很轻微，斑点的中心稍微隆起，但随着果实成熟，这些环状斑点在多个同心环的着色中变得更加明显。

TSWV 与其他斑萎病毒相比是独一无二的，其宿主范围广泛，包括 1000 多种植物并对许多农艺和园艺作物造成重大经济损失。TSWV 可能在一些地区随处可见，在这些地区，它能够侵染许多杂草、园林植物甚至本地植物，使其能够轻松地在不同番茄生产季节之间架起桥梁。由于这些原因，大多数的 TSWV 管理策略依赖于限制或消除蓟马媒介和使用抗性品种。

## 机械传播烟草花叶病毒（TMV）和番茄花叶病毒（ToMV）

> 本节内容来源于《中宁越夏小番茄种植手册 3.11》。

TMV 和 ToMV 都是烟草病毒属的成员，阳性 RNA 病毒由外壳蛋白形成的直杆病毒颗粒组成。由于 TMV 和 ToMV 在宿主范围和血清学属性上高度相似，它们通常被归为一类。这两种病毒引起的病害最常见的症状是叶片上有浅绿和深绿色的斑纹。这些受影响的叶片通常卷曲、变小、形状畸形；整株植物的生长可能有些许发育不良。果实的症状通常包括成熟不均匀以及大小和数量的减少，尽管果实在高温下会形成黄圈或者在绿熟期果实形成内部褐变（类似于灰球）；偶尔也会发生其他形式的果实畸形。总体而言，植物症状受病毒株、番茄品种、植物生长阶段相关的侵染时间、温度和光质的影响很大。高温和低光照强度会加剧症状。然而，如果在高温下暴露于 TMV 或 ToMV，具有 Tm-2 和 Tm-22 抗性基因的番茄品种会表现出严重的坏死反应。

由于其外壳蛋白结构，TMV 和 ToMV 可能是植物界最持久和最具传染性的病毒。这两种病毒都是通过人类活动造成的机械传播。番茄生产中常见的活动，如嫁接、移植、吊蔓、绕蔓、修剪和收获，容易传播病毒。由于 TMV 可以在烟草制品中存活，因此应禁止在番茄生产附近使用烟草制品，工作人员应在进行农事操作之前和期间洗手以灭活病毒。这两种病毒也可以通过种子传播，因此鼓励使用专门的消毒剂或热处理种子。应避免出现问题的田地，因为 TMV 和 ToMV 可以在植物残株（包括根系）中长期存活。
