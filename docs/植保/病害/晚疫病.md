# 晚疫病

晚疫病是番茄和马铃薯最具破坏性的叶面病原菌之一，由类似致病疫霉菌引起。在番茄上，这种病害会影响叶片、茎和果实。

叶面侵染最开始是浸润状的病斑，随着病斑的扩大，变为棕色和坏死。在低温高湿的条件下，通常可以在发病叶片下方和病斑边缘看到白色菌丝体和孢子。通常，病斑周围的健康叶片组织呈浅绿色。迅速扩张的病变可呈带状。在有利的条件下，当病斑合并或真菌发展到叶柄时，组织迅速枯萎。迅速坏死使枯萎组织呈现出独特的浅棕色皱缩外观，特别是如果组织没有被其他腐生生物侵染，就好像它们被烧伤或暴露在霜冻中一样。茎和叶柄也可以被直接感染，以类似于叶片侵染的方式进行病变，被真菌包围，导致叶片枯萎。感染开始时果实上有深绿色油斑，随着果实开始成熟，这些油斑最终变成浅棕色或灰色。随着病斑的扩大，果实病斑也会呈现带状，在低温高湿的条件下，病斑表面会出现白色菌丝体和孢子。

该病原体通常一季又一季在受感染的果实（病株）、自生番茄和马铃薯植物上存活，大多数温带气候下需要在活体组织越冬。然而，在世界上的一些地区，存在两种交配类型的真菌菌株，使真菌能够产生一种特殊的厚壁结构，称为卵孢子，可以在土壤或植物残株中生存。病害发展可能很快，尤其是在有利于孢子形成的条件下；最佳条件为 91%~100% 的相对湿度和 18~22°C 的温度，但在低至 3°C 和高达 26°C 的温度下仍可产生孢子。

除了在有利于发病的条件下使用干净的移植作物和及时应用预防性杀菌剂外，销毁病株和自播苗的环境卫生对控制其传播至关重要。

## 防治方法

可用 69% 烯酰·锰锌可湿性粉剂 600~800 倍液、72% 霜脲·锰锌可湿性粉剂 600 倍液等喷雾。晚疫病发生严重时，应选用复混剂，如 68% 精甲霜·锰锌水分散粒剂 500 倍液 + 25% 吡唑醚菌酯乳油 1500 倍液，或用 52.5% 噁酮·霜脲氰水分散粒剂 1000 倍液 + 50% 烯酰吗啉可湿性粉剂 800 倍液等喷雾。
