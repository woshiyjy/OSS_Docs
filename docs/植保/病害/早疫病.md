# 早疫病

一般来说，这种疾病主要是由于真菌茄链格孢菌引起的，但最近的研究发现了其他能够引起番茄早疫病症状的格链孢菌，包括番茄嗜酸链格孢菌和巨孢链格孢菌。

早疫病的症状由浅棕色到深棕色的圆形病斑组成，病斑随时间的推移而扩展，形成特征性的明暗交替同心轮纹。病斑周围可能有黄色褪绿组织，随着病斑的扩大合并，整个叶片可能变黄。该病通常始于老叶，但也可能发生在茎和果实上。严重的茎部病斑可能会造成断枝。果实感染通常开始于花萼附近的果实顶部或茎与果实相连的地方，病斑扩大也会形成同心轮纹。幼苗和移栽植物被侵染通常会导致茎腐烂，迅速传播，导致幼苗死亡。

适宜的温度（24~29°C）和频繁的降雨或大量露水可促进孢子萌发有利于病害发展。在游离水的理想条件下，孢子在 2 小时内萌发，在 2~3 天内形成可见的病斑。这种真菌产生的孢子随气流散播到其他易感植物上。此外茄链格孢菌可以产生称为厚垣孢子的特殊结构，这种结构可以在土壤中存活长达一年。

这种真菌在种子、受感染的植物残体、自生番茄和其他茄科杂草上存活，强调了环境卫生和轮作对控制这种疾病的重要性。适当施肥保持旺盛生长也是至关重要的，因为衰老组织最容易受到真菌的侵染。最后，在环境条件有利于疾病的情况下及时使用保护性杀菌剂，往往是进行有效管理的必要条件。
