# 叶霉病

黄枝孢菌是叶霉病的病原菌。叶霉病的叶面症状通常从老叶发病，由上叶表面的淡绿色或黄色斑块组成，最终变为亮黄色。受影响叶片的下侧有橄榄绿霉菌斑；与未受影响的组织相比，霉菌周围的组织通常为淡绿色或白色。受影响的叶片最终会卷曲脱落。该病通常仅限于老叶，但也可在新叶上发生，甚至可在有利条件下影响叶柄、花序梗、茎、花和果实。受影响的果实茎端会出现黑色干腐。

该病在温室生产中更为常见，但也可能在田间发生，相对湿度高于 85%，温度为 22~24°C 有利于该病发生，症状在 4~32°C 时也可能出现。

保持环境卫生和控制湿度是控制温室生产中该病的关键。孢子很容易分散在空气中，真菌在叶组织上可作为腐生生物存活于土壤中。因此，及时清除和销毁感病植物，以及将相对湿度保持在 85% 以下，可以限制该病害。吊蔓和修剪植物也可以通过改善空气通过冠层的流速来帮助降低相对湿度。几种赋予宿主抗性的基因已知并广泛应用。

## 防治方法

可用 60% 咪鲜胺可湿性粉剂 800 倍液、60% 噻菌灵可湿性粉剂 700~800 倍液、30% 苯甲·丙环唑乳油 3000 倍液、32.5% 苯甲·嘧菌酯悬浮剂 1500 倍液等喷雾。
