# 植保

本板块收录口感番茄生产中的作物保护与调节知识，内容主要来源于《海原小番茄越夏茬口种植管理手册》（20260704）第 10 章及第 13 章附录，并与《中宁越夏小番茄种植手册 3.11》交叉校对。

植保手段最常用的即是叶面喷雾的人工打药方式，通常采取杀菌剂、杀虫剂、叶面肥等复配形式，前期 15-20 天一次，降雨前后、病害发生后增加使用次数，可 7-10 天一次。除化学农药外，还可积极采用物理防治方法，如悬挂黄篮板（密度）诱捕器，安装杀虫灯等。
