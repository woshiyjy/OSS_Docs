# 白粉虱

## 生活史

白粉虱的一生分为成虫、卵、若虫和伪蛹四个阶段。成虫具有飞行能力，喜欢在嫩叶上产卵，若虫和成虫都会吸取叶片汁液，对植物造成危害。白粉虱适宜在 22°C~30°C 的温度下繁殖，具有趋嫩、趋黄、趋光的特性。白粉虱的繁殖速度非常快，从卵到成虫只需 23 天，且世代重叠严重，难以通过一次用药彻底防治。

## 危害症状

- **叶片褪绿和黄化**：白粉虱的成虫和若虫喜欢群集在番茄叶片的背面，以刺吸式口器吸取植物汁液，导致叶片褪绿、黄化、萎蔫，严重时甚至全株枯死。
- **煤污病**：白粉虱在吸取汁液的同时会分泌大量蜜液，这些蜜液会污染叶面和果实，导致煤污病的发生。
- **病毒传播**：白粉虱不仅是番茄的主要害虫之一，还常常作为病毒病的传播媒介，进一步加剧了番茄的病害问题。

## 防治方法

**物理防治**：悬挂黄板粘杀成虫，通风口设置防虫网防止外来虫源进入。

**农业防治**：适当种植白粉虱不喜欢的作物如芹菜、葱、蒜类，合理轮作倒茬。

**生物防治**：在白粉虱发生早期人工释放丽蚜小蜂等天敌进行生物防治。

**化学防治**：使用吡虫啉、噻虫啉、噻虫嗪、吡丙醚、烯啶虫胺、呋虫胺等药物进行防治，注意轮换用药以避免抗药性的产生。
