# 装车与运输

装车前应检查车厢卫生、预冷状态、温度记录设备、装载稳定性和通风条件。产品不应直接接触污染表面，不应与有毒有害、异味或可能造成污染的货物混装。

装车和运输温度应结合产品目标市场、运输时间、成熟度和客户要求确定。到货后应收集温度、包装、机械伤、腐败和果蒂状态反馈，作为工艺调整依据。
