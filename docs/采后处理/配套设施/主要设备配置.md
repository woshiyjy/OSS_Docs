# 主要设备配置

## 设备清单

加工中心宜根据规模配置以下设备：

- 六口或其他适宜规格的分选设备；
- 上料、输送、缓冲、收集和包装辅助设备；
- 清洗、整筐浸泡或经批准的其他处理设施；
- 首次预冷设施；
- 制冷、通风、按需加湿和除霜排水设施；
- 环境温湿度记录仪、果心温度计、计时器和报警装置；
- 电子秤、计量容器、处理液检测和记录工具；
- 周转筐清洗消毒设备和卫生工具；
- 叉车、地牛、手推车等搬运设备；
- 减振垫、缓冲垫和落料高度调整装置；
- 备用电源或停电应急保障设施；
- 人员防护、洗眼、冲洗、通风和泄漏应急设施。

设备说明书额定参数、厂家宣传参数和企业实测能力应分别记录。

## 主要设备配置表

| 类别 | 基本配置 | 选型重点 |
|---|---|---|
| 分选 | 六口或适宜规格选果机 | 企业实测产能、落差、缓冲、清洁便利性 |
| 清洗处理 | 清洗设施、浸泡池或处理槽、沥液架 | 材料相容性、容量、排水、通风、计量和人员安全 |
| 预冷 | 专用预冷库或强制风冷/压差风冷装置 | 风量、静压、气流密封、包装阻力、热负荷 |
| 制冷 | 与峰值装载和开门负荷匹配的制冷系统 | 冷负荷、备用能力、除霜和温度均匀性 |
| 湿度 | 按监测结果配置的加湿设施 | 防结露、可清洁、水质和自动控制 |
| 监测 | 温湿度记录仪、果心温度计、报警和计时设备 | 点位、校验、数据保存和异常报警 |
| 搬运 | 地牛、手推车、叉车或其他适宜工具 | 平稳、限速、转弯半径和减振 |
| 安全 | 通风、PPE、洗眼/冲洗、泄漏应急、备用电源 | 与处理剂和制冷系统风险相匹配 |

## 周转容器配置表

| 环节 | 初步建议 | 控制要求 |
|---|---|---|
| 田间采摘 | 通风、可堆码、浅型周转筐；单筐约 30～40 斤 | 禁止抖实和过量装载；实际载量需验证机械伤 |
| 分选后周转 | 约 20 斤食品接触用塑料筐 | 分级标识、稳定码放、按工艺铺设内衬 |
| 强制风冷 | 约 5% 有效开孔率作为首轮检查值 | 开孔连续对齐，不得被内衬或错误堆码遮挡 |
