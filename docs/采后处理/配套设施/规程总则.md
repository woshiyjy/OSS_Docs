# 规程总则

## 前言

本文件以宁夏樱桃番茄产业实践为基础，重点吸收中宁县等产区的生产与加工经验，针对越夏生产条件下采后环境温度较高、原料集中到货、既有冷库条件差异较大、加工主体规模不一等实际情况，提出樱桃番茄采后处理设施配置、工艺流程、关键参数、过程监测和质量安全管理的基本要求。

本文件坚持因地制宜、流程衔接、风险控制和持续验证原则，在总结企业实践的基础上，吸收果蔬采后处理、冷链物流、设施设备和食品安全相关资料，形成可用于项目建设、企业管理、技术培训和示范推广的技术框架。

本文件尚未完成全部参数的现场核定。标注为"待验证""待核定"的内容，不应作为未经批准的生产指令。

## 范围

本文件规定了樱桃番茄采后处理的术语和定义、总体要求、加工单元规划、场址与动线、功能区域、设施设备、周转容器、工艺流程、冷链控制、清洗与处理、质量监测、人员管理、安全管理、记录追溯和异常处置要求。

本文件适用于宁夏冷凉区及相近生产条件下樱桃番茄采后处理中心的新建、改造、运行管理和技术评价。其他地区、其他品种或不同成熟度产品参照使用时，应重新验证关键参数。

## 术语和定义

### 樱桃番茄

果实较小、可鲜食并兼具蔬菜和水果消费属性的番茄类型。本文件所指产品以单果采收、保留果蒂或果托的商品果为主。

### 采后处理

樱桃番茄采收后，为保持质量、降低损耗并满足销售要求而实施的田间暂存、运输、分选、清洗、处理、预冷、贮藏、包装、发运及相关监测活动。

### 标准化加工单元

围绕一定服务面积和高峰日处理量配置的人员、场地、生产线、处理设施、冷库、包装区和辅助设施组合。标准化加工单元是项目规划和扩展的基本模块，不等同于固定不变的建设规模。

### 首次预冷

原料完成分选和规定处理后，通过冷库、强制通风或压差风冷等方式，尽快移除田间热和加工过程中吸收的热量，使产品进入短期周转或后续贮藏条件的过程。

### 成品短期暂存

产品在约 18℃环境快速完成订单化包装和整垛缠绕后，直接转入 8～10℃成品冷库进行短时间存放和待发管理的过程。本项目现行工艺不设置独立的包装后二次压差预冷。

### 强制风冷

利用风机建立空气压差，使冷空气按规定方向通过包装通风孔隙和产品间隙，从而提高产品换热效率的预冷方式。

### 果心温度

用于反映果实内部实际热状态的代表性温度。果心温度与库温、出风温度、包装区温度或车厢温度不应混同。

### 机械损伤

产品在采收、装筐、搬运、运输、分选、落料、浸泡、包装和装车过程中，因碰撞、挤压、摩擦、跌落、振动或刺伤形成的可见或潜在损伤。

### 批次

在相对一致的基地、地块、品种、采收日期、采收班组和处理条件下形成，并能够通过记录进行识别和追溯的一组产品。

### 冷藏库

通过制冷和保温设施，使库内环境维持在产品规定的非冻结温度范围，用于预冷、短期周转、较长期贮藏或成品待发的库房。本规程所称"冷库"均指冷藏库，不包括以冻结产品或 0℃以下长期储存为目的的冷冻库。

## 总体要求

### 全过程时效控制

采后处理应按照"及时采收、及时遮阴、及时转运、及时分选、及时处理、及时预冷、按计划分流、及时包装和及时发运"的原则组织生产。

加工中心应以小时为单位管理原料从采收至加工、从规定处理至首次预冷、从包装开始至成品入库以及从成品出库至装车的时间，避免无工艺目的的等待和积压。

### 三项核心控制

各岗位和各工艺环节应同时落实以下控制：

- **机械损伤控制**：降低碰撞、挤压、振动、跌落和摩擦；
- **微生物风险控制**：通过环境卫生、容器清洁、清洗处理、人员卫生和过程分区降低腐败及交叉污染风险；
- **温湿度控制**：降低不必要的高温暴露，保持适宜相对湿度，同时防止结露、可见水膜和积水。

### 监测与反馈

加工中心应具备环境温湿度、代表性果心温度、时间和处理过程的监测能力。监测结果应能够用于调整制冷、通风、加湿、装载、处理节拍和发运计划，不得仅记录而不处置。

### 地方化工艺验证

采用与通用教材或外部指南不同的地方化工艺时，应记录其目的、操作条件、验证结果和适用边界。未经验证的经验参数应标注为待验证，不应表述为普遍适用结论。
