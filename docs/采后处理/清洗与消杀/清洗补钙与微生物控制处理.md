# 清洗、补钙与微生物控制处理

## 处理工艺

企业现行地方化工艺采用氯化钙进行补钙，并采用亚氯酸钠与柠檬酸按受控方式活化生成二氧化氯，用于规定环节的微生物风险控制。该工艺的具体产品、法规身份、配制顺序、浓度、pH、接触时间、使用次数、残留和废液处置，应由技术负责人依据产品标签、法规要求和验证结果批准后写入专用 SOP。

项目现有流程为：配制并按规定时间活化母液；将分选后的产品按等级装入约 20 斤黑色塑料筐并铺设内衬；整筐浸泡约 3 min；提出后充分沥液；随后进入首次预冷。该流程属于企业地方化实践，正式应用前应持续验证果实开裂、漂白、风味、果蒂状态、腐败率、残留和人员安全风险。

现阶段不得在本规程正文中固化尚未批准的各成分投加量。每槽或每批处理液均应记录产品名称、批号、水量、投加量、活化时间、实测控制指标、开始和结束时间、处理批次、操作人员和复核人员。

处理区域应专用、通风并限制无关人员进入。操作人员应使用规定的个人防护用品；不同产品不得在无相容性评估的情况下混合；不得使用金属或其他不相容工具；发现刺激性气味异常、泄漏、人员不适或检测值超限时，应立即停止作业并按应急预案处置。

## 沥液

浸泡后应在洁净区域充分沥液，避免大量处理液带入冷库。沥液时间和判定方式应结合包装、预冷、果面水膜和腐败风险进行验证。

## 微生物风险控制

### 基本要求

微生物风险控制不得仅依赖某一种处理剂，应建立原料剔除、环境卫生、人员卫生、容器清洁、用水管理、处理剂控制、温度管理和交叉污染防控的综合体系。

### 卫生管理

应制定生产前、换批、班中和生产结束后的清洁消毒计划。清洁工具应分区、标识并妥善存放。周转筐、输送设备、浸泡设施、地面和排水系统应按规定频次清洁，并记录执行和检查结果。

处理液不得无限期或跨批无条件重复使用。更换条件应根据处理量、浊度、有机负荷、实测有效指标和验证结果确定。
