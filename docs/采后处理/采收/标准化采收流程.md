# 标准化采收流程

## 采摘时机

- 1 穗果成熟比例达到 **50%** 即可开始采收
- 红果：果色大于 #10 号色，糖度达标后采摘

## 采摘要求

1. 成熟度合格的一次性采摘干净，**不要遗漏**
2. 上午采果筐内套膜袋，**下午高温不套膜袋**
3. 转运筐上覆盖湿毛巾/湿布/湿报纸/叶片，**防止果托萎蔫**
4. **避强光和高温**储存，不要在田间过长时间堆放
5. 采果桶和裂果桶**各一个**，用不同颜色和大小区别，不要混放

## 采摘温度控制

番茄是典型的**呼吸跃变型**蔬菜，采摘后呼吸作用仍在继续。温度越高呼吸越强烈，达到阈值即引起衰败（软果），导致商品率下降和货损。

### 降温措施

- 采摘选择**温度较低的清晨**
- 采摘后在田间通风阴凉处搭盖遮阳棚，避免阳光直射
- **快速送往加工中心**进行分拣和预冷，不要在高温下长时间堆放
- 运输过程中保持合理温度，装车后加盖遮阳措施，确保通风正常

## 采摘机械伤控制

- **轻拿轻放**，不使用太大的筐（避免自重压迫）
- 运输路线确保没有过度颠簸的坑洼，或叮嘱驾驶员缓慢通过

## 采后加工流程

1. 到达加工车间 → 天气清凉可直接加工；天气炎热先**喷淋降温**
2. 如有田间泥土 → 再进行一次消杀
3. 上分选线 → 水洗程序 → 按指定要求添加保鲜剂
4. 分选加工完成后存入冷库指定位置

**关键流程顺序**：先加工 → 再预冷 → 再冷藏。预冷快速降低果核温度后再转入冷库。

## 采摘前准备

- 采收前需通过第三方检测（参考标准：农残限量 ≤ 0.01mg/kg，重金属镉 ≤ 0.05mg/kg）
- 检测不合格批次**禁止流入加工环节**，启动追溯机制排查污染源
