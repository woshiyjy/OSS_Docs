# 采收计划与成熟度

生产前应根据订单、运输距离、预计销售周期、天气和库容制定采收计划。应明确品种、地块、采收成熟度、采收时段、班组、预计数量和到厂时间。

成熟度标准和分级色卡在正式版本中另行规定。不同品种和成熟度不得未经验证直接采用相同贮藏和处理参数。
