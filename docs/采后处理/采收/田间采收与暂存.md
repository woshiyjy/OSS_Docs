# 田间采收与暂存

在越夏高温条件下，宜优先安排清晨采收，减少高温时段采收和暴晒。采后产品应及时转移至遮阴、通风和洁净区域，避免直接置于高温地面或阳光下。

田间喷洒补水或处理剂时，应使用经批准的产品和受控配方，记录名称、批号、浓度、时间、操作人员和适用地块。不得以补水形成持续果面水膜或增加腐败风险。

采摘人员不得通过剧烈晃动、抖实或过度装满周转筐减少往返次数。果实应轻放，控制落差，并及时剔除破损、流汁、严重病害和污染果。

## 采摘周转筐

采摘周转筐应满足食品接触安全、表面光滑、易清洗、通风良好、可稳定多层堆码和不易变形等要求。筐体不应过深，装载后不得造成下层果实明显受压。

项目初步建议单筐装载量控制在 30～40 斤范围内。实际允许装载量应结合筐体尺寸、果实硬度、成熟度、堆码层数、运输振动和机械伤率验证；出现压伤、果蒂脱落或筐体变形时应降低装载量。
