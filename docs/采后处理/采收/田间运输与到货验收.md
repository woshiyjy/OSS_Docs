# 田间运输与到货验收

## 田间运输

运输车辆应清洁、平稳并具备遮阳、防雨和必要的通风条件。周转筐应稳定码放并采取防滑、防倒和减振措施。

车辆通过减速带、坑洼、台阶和转弯路段时应提前降速。加工中心应将运输路线中的持续振动点纳入机械损伤排查清单。

## 到货验收

到货后应核对基地、地块、品种、采收时间、数量、运输时间和田间处理记录，并抽测环境温度、代表性果心温度、成熟度、机械伤、病害和果蒂状态。

不符合要求的批次应隔离、标识并由质量负责人决定返工、降级、快速处理或拒收，不得未经处置直接混入正常批次。

到货后不单独设置"先预冷、后加工"的等待环节。验收合格产品宜按批准方案进行简单喷淋保湿，并尽快进入分选和后续处理。喷淋操作应控制用水卫生、用量和果面水膜，避免以保湿为名造成积水或交叉污染。
