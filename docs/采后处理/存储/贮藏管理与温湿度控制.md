# 贮藏管理与温湿度控制

## 冷藏库功能与温度目标

标准化加工单元配置 3 间功能明确的冷藏库，每间冷藏库的建议功能为：

- **首次预冷库**，目标温度约 10℃；
- **预冷后短期周转、成品短期暂存及待发保鲜库**，目标温度 8～10℃；
- **预计存放超过 3 天产品的较长期冷藏库**，目标温度约 5℃。

订单化包装作业区环境温度目标约 18℃。

## 温度与相对湿度控制原则

产品自田间采收起即进入温湿度管理范围。遮阴、运输、分选环境、处理后沥液、首次预冷、分流贮藏、快速包装、成品暂存和发运应连续衔接，尽量减少高温暴露和温度反复波动。

## 温度口径

企业当前工艺口径如下：

| 工艺环节 | 目标环境温度 | 状态与说明 |
|---|---|---|
| 首次预冷 | 约 10℃ | 企业现行地方工艺口径 |
| 预冷后 3 天以内短期周转 | 8～10℃ | 包括分选后周转和订单匹配 |
| 预计存放超过 3 天的较长期贮藏 | 约 5℃ | 应提前按计划分流 |
| 订单化包装作业区 | 约 18℃ | 控制作业时长 |
| 包装后成品短期暂存及待发 | 8～10℃ | 整垛缠绕后直接入库，不单设二次压差预冷 |

上述数值主要指环境运行目标。产品是否达到工艺要求，应结合代表性果心温度、时间和均匀性判断。

## 相对湿度口径

预冷和相关贮藏环境相对湿度控制方向为 90%～95%。果蒂、果托萎蔫可作为失水风险信号之一，但不得仅凭感官判断启动持续加湿。应结合仪器记录、结露状态和产品抽检进行调整。

## 相对湿度和结露控制

预冷及相关贮藏环境的相对湿度控制方向为 90%～95%。加湿设施应根据监测结果、产品失水情况和冷库运行状态配置与启停，不得以形成果面水膜、包装滴水或库内积水为代价提高湿度。

相对湿度控制应兼顾果实失水和果蒂、果托新鲜度。发现结露时，应调整温差、风速、装载、开门时间和加湿策略，并对微生物风险进行复核。
