# 存储管理

## 冷藏管理

冷藏主要是在**等待物流前的短时间存储**，不同于预冷（预冷是快速降温）。

### 库房衔接要求

- 预冷库和冷藏库之间最好**可直接连通**，不需经过常温区转运
- 冷藏库到冷藏车之间也**不要在室温下转运**
- 建议流程：冷藏车**先打冷** → 冷库外通道内**快速完成装车**

### 存储环境

- 避强光和高温
- 不要在田间或常温区过长时间堆放
- 番茄是呼吸跃变型蔬菜，温度越高呼吸越强烈，达到阈值即引起衰败（软果）

## 加工后流程

```
分选加工 → 预冷（快速降果核温度）→ 冷藏库存储 → 冷藏车装车发运
```
