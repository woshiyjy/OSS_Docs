# 订单化包装与成品入库

## 包装作业区与包装材料库

单线加工单元的温控包装作业区推荐面积为 160～180 m²；双线加工单元推荐面积为 260～280 m²。包装作业区应满足订单复核、人工复选、称量、装箱、码垛、整垛缠绕、成品复核和人员通行需要。

加工中心应设置包装材料库。单间包材库推荐面积为 100～150 m²；单线单元原则上配置 1 间，双线单元宜配置 1～2 间，并可根据纸箱、塑料膜、泡沫箱、周转筐和其他包装材料的使用量进行分库或分区管理。

纸箱、塑料膜、泡沫材料等具有较高可燃负荷。包材库的防火分区、耐火等级、疏散、消防给水、自动喷水灭火系统、火灾自动报警系统和灭火器配置，应符合现行国家工程建设消防技术标准及当地消防审查要求。宜配置自动喷水灭火系统和火灾自动报警装置；当依法无需设置自动喷水灭火系统时，仍应配置适用的火灾探测报警、灭火器材和日常巡查措施。火灾自动报警装置不得替代依法应设置的自动喷水灭火系统。

包材不得无序集中堆放，不得占用疏散通道、安全出口、消防设施操作空间和消防车通道。应根据材料性质设置堆垛间距、隔离分区和人员灭火通道，控制堆垛高度，并将充电、热源、明火和动火作业与包材储存区分离。包材库应明确责任人，开展定期巡查并保存记录。

耐候性较好的塑料周转筐和短期内能够使用完毕的塑料包装筐，可在具备防雨、防污染、防倒塌和消防隔离条件的室外区域短期堆放，建议不超过 10～15 d。长期储存或纸质包材不得采用露天堆放；室外堆放还应控制日晒老化和风化风险。

包装作业区附近应设置包装盒折叠和临时生产准备区域，用于将平面纸板沿预压线折叠成盒、临时存放当班包材和组织人工操作。该区域不得占用主物流通道、疏散通道和消防设施操作空间。

## 订单化包装

产品宜在约 18℃温控环境中进行订单化包装。包装前应核对客户、规格、等级、批次、数量和包装材料。包装过程应控制操作时间，避免产品长时间滞留在包装区。

包装材料应清洁、干燥、无异味，并满足食品接触和运输强度要求。采用塑料缠绕膜时，应以码垛后的整垛产品为基本缠绕单元，明确膜材、层数、底部和顶部处理方式。缠绕膜用于减少短时温湿度波动和增强运输稳定性，但不得完全封堵包装通风孔、托盘底部回风通道，或造成结露和异常气体积累。

## 成品入库与待发

包装作业应采用边领料、边包装、边入库的连续组织方式。产品在约 18℃作业区快速完成包装、码垛和整垛缠绕后，直接转入成品冷库，不再单独实施包装后二次压差预冷。

成品冷库目标温度为 8～10℃。包装完成、整垛缠绕后直接入库，并抽测一次代表性果心温度。入库和放行时宜记录批次、包装结束时间、入库时间、库温、代表性果心温度、出库时间和装车条件。果心温度用于掌握产品状态，不再设置独立的包装后预冷完成判定节点。
