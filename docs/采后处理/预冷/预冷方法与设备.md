# 预冷方法与设备

## 预冷 vs 冷藏

| 维度 | 预冷 | 冷藏 |
|------|------|------|
| 目的 | 快速降温，降低呼吸作用，提升果品质量，延长货架期 | 等待物流前的短时间存储 |
| 降温速度 | 快（快速降低果核温度） | 慢（维持低温） |
| 流程位置 | 加工后 → 预冷 → 冷藏 | 预冷后 → 冷藏 → 发车 |
| 库房 | 预冷库 | 冷藏库 |

## 流程顺序

```
加工 → 预冷（快速降低果核温度到适宜温度）→ 转入冷藏库 → 冷藏车发运
```

⚠️ **不能跳过预冷直接冷藏**：传统冷库直接打冷降温慢，无法快速降低果核温度，而预冷可快速将果核温度降至目标值。

## 库房衔接

- 预冷库和冷藏库之间最好**可以直接连通**，不需要经过常温区转运
- 冷藏库到冷藏车之间也不要在室温下转运
- 建议：冷藏车先打冷，在冷库外通道内**快速完成装车**

## 预冷前准备

分拣加工完成后**务必先进行预冷**，预冷到果核温度达到适宜温度后再转入冷库。
