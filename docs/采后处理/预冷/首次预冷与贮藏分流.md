# 首次预冷与贮藏分流

沥液完成后应尽快进入首次预冷，首次预冷目标温度约为 10℃。完成首次预冷、预计 3 天以内周转的产品进入 8～10℃短期周转路线；预计存放超过 3 天的产品应根据计划及时转入约 5℃较长期贮藏路线，不应先在短期库放满 3 天后再转库。

预冷结束判定不得仅依据库温或运行时间，应结合代表性果心温度、批次温度均匀性和后续用途。具体果心温度终点和允许偏差列为现场验证参数。

## 预冷能力

首次预冷库宜具备与产品包装和装载方式相匹配的强制通风或压差风冷能力。既有冷库不具备专门预冷功能时，可在完成制冷能力、气流组织、电气安全和食品卫生评估后，配置移动式或固定式强制风冷装置。

简易改造不得替代必要的工程核算。风机选型应依据风量、静压、包装阻力、装载量和目标冷却时间确定，不应仅按风机功率或外观尺寸选型。

## 通风要求

用于强制风冷的周转筐、内衬和外包装应形成连续的进风和出风通道。开孔不得被内衬、标签、相邻筐体或错误堆码遮挡。

约 5% 有效开孔率可作为首轮工程检查基准，但正式值应通过实际包装阻力、风量、静压、冷却曲线、失水和机械强度综合验证。约 25 Pa 静压下 2～3 CFM/lb 可作为试验起点，100 Pa 仅作为高阻力包装或特定装载条件的试验工况，不作为普遍强制值。
