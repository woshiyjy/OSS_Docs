# 分选作业

分选前应检查输送带、落料口、缓冲垫和收集筐状态。产品在设备内的落差、滚动距离和相互挤压应尽量减小。

分选应按照经批准的商品等级要求，剔除裂果、软果、病果、严重机械伤果、污染果和其他不合格果。分选线各出口应配置完整缓冲材料，缺失或移位时应停机纠正。

## 分选后周转筐

分选后产品可使用约 20 斤规格的食品接触用塑料筐，并根据企业工艺铺设适宜内衬。周转筐应分级标识、整齐码放并防止交叉混批。
