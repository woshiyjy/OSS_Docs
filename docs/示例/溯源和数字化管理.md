# 溯源和数字化管理

## 区块链溯源系统部署

在种植基地部署物联网传感器（土壤温湿度、光照强度、空气温湿度），数据实时上传至区块链平台。

每批次番茄采收时生成唯一溯源二维码，记录种植地块、施肥记录、农残检测结果。

### 操作流程

1. 定植后为每个种植计划建立档案
2. 关键农事操作（施肥、打药、采收）通过录入数据
3. 由系统生成溯源码贴于包装上

### 农残与重金属检测标准

采收前需通过第三方检测。参考标准：

- 农残限量 ≤ **0.01mg/kg**（欧盟标准）
- 重金属镉 ≤ **0.05mg/kg**

检测不合格批次禁止流入加工环节，并启动追溯机制排查污染源（如土壤、水源、肥料）。

## 数字化种植管理

### 智能灌溉与施肥优化

升级水肥一体化系统，尽可能使用支持手机远程开关的电磁阀/电动阀和恒压供水系统，提升灌溉效率和稳定性。如果能有流量监测或者定时定量灌溉功能最佳。

灌溉量参考：

| 土壤类型 | 灌溉量 | EC 值控制 |
|----------|--------|-----------|
| 沙土 | 每日 ≤ 20m³/亩 | 0.8～1.2 mS/cm |
| 黏土 | 每 2 日 ≤ 15m³/亩 | ≤ 1.5 mS/cm |

施肥方案动态调整：膨果期增加钾肥比例（N-P-K = 1-1-2），通过云端算法匹配胖东来复合番茄汁的糖度需求（目标 ≥ 10°Brix）。

### 环境监测

在部分具有代表性的棚内安装 4G 太阳能供电的免维护多要素传感器和免流量传感器。一般情况下，每个种植计划或每 50 亩可以安装一套。
