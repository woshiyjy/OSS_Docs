# 山东产区秋延茬口种植

山东产区秋延茬口是衔接夏秋的重要种植季，8 月份定植、11 月份上市。

## 茬口时间线

- **定植**：8 月份
- **上市**：11 月份左右
- **结束**：短茬 12 月结束；长茬（秋延+越冬+春延）持续至次年 6 月

## 两种栽培模式

### 土壤栽培

- 传统方式，详见 [山东产区](../产区/山东产区.md)
- 需注意重茬导致的土传病害

### 日光温室基质栽培

- 基质条栽培，精准水肥管控
- 定植前 1～2 天用营养液将基质条滴灌饱和
- 8、9 月高温期重点管理：病毒病预防、白粉虱防治、徒长控制、花芽分化
- 白天温度高于 35℃ 时遮阴（11:00～15:00，每天不超过 5 小时）

**定植操作要点**：

1. 基质条上按压成孔 → 放入苗 → 轻压基质使根系紧密接触
2. 定植后立即滴灌一次
3. 3 天内遮阴，避免强光直射
4. 缓苗后（约 5～7 天）开始正常水肥管理

最佳定植时间：阴天或晴天下午。

## 高温期管理重点

| 要点 | 措施 |
|------|------|
| 病毒病 | 蘸根（苗迪发+亮盾）+ 独静滴灌 + 遮阴降温 |
| 白粉虱 | 英壮滴灌（内吸性强，持效期长） |
| 徒长 | 营养调控平衡营养与生殖生长 |
| 花芽分化 | 叶喷促花方案（盈花宝/花果丰/花脉动） |
