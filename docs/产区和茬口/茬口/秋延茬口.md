# 秋延茬口

秋延茬口是山东产区的重要种植茬口之一，秋季定植、冬季收获。

## 山东产区秋延茬口时间线

### 短茬模式（秋延）

- **定植**：每年 **8 月份**（与长茬同期定植）
- **上市**：**11 月份**左右
- **结束**：**12 月份**结束
- **总周期**：约 4 个月

### 长茬模式（秋延 + 春延）

- **定植**：每年 **8～9 月份**
- **上市**：**11 月份**左右
- **结束**：持续至次年 **6 月份**
- **总周期**：约 **8 个月**（跨越秋、冬、春三季）

## 茬口特点

- 秋延茬口定植期处于夏末秋初，温度逐渐下降，需要防范高温向低温转换期间的病害风险。
- 短茬秋延适合快速周转，降低冬季管理成本和风险。
- 长茬模式可充分利用设施条件，实现跨季持续采收，总产量更高。

## 品种选择考量

- 秋延茬口涉及温度从高到低的转换期，**不抗 TY 病毒的品种（如釜山88）** 需要特别注意避开易产生病毒的温湿度阶段。
- 抗性好的品种（如鸿运九九、首而红）在秋延茬口有更强的茬口适配性。
