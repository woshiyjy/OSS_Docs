# 越夏茬口

越夏茬口是夏季高温季节的种植茬口，4-10 月为采收期。越夏种植对品种的耐热性和抗逆性要求较高。

## 品种在越夏茬口的表现差异

### 釜山88系列的通病：容易掉花掉果

釜山88系列品种（包括釜山88、鸿运九九、首尔红）在越夏茬口种植时存在一个**通用性问题**：

- 在越夏高温环境下，**一碰就容易掉果子**。
- 这对人工操作（如整枝、采收、喷药等）提出了更高的要求，稍有不慎就会造成落果损失。

### 高丽红：越夏表现优异

高丽红（高俪红）在越夏茬口有显著优势：

- **不容易掉花掉果**，在同等高温和操作条件下保持率更好。
- 耐高温性状表现良好。
- 耐裂性红果最高，挂树时间可额外延长一个月。

### 圣红2号：抗高温特性

- 圣红2号（圣宏2号）以**抗高温**特点见长。
- 山东产区越夏种植可优先考虑。

## 越夏茬口的病害风险

- 越夏期间温度高、湿度变化大，**TY 病毒**易发。
- 不抗 TY 病毒的品种（如釜山88）在越夏茬口需要更加谨慎，要避开易产生病毒的温湿度阶段。
- 建议越夏茬口优先选择**抗 TY 病毒**的品种（鸿运九九、首尔红、高丽红、圣红2号）。
